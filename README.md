# LocalMusicPlayer

LocalMusicPlayer is a privacy-first, offline Android music player designed for large personal MP3 libraries. The project is currently in its approved design phase; implementation has not started.

The application will support user-selected folders, selected individual MP3s, and optional user-authorized discovery through Android's shared media library. It will omit internet and all-files permissions, support reliable background playback and Samsung earbud controls, and provide portable USB-visible backups.

See the [approved design specification](docs/superpowers/specs/2026-08-20-private-android-music-player-design.md) for the complete V1 behavior and constraints.
